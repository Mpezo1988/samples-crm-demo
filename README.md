# Samples CRM (demo)

A lightweight CRM for tracking product sample requests from first shipment through to a purchase order, built as a single page that runs in the browser.

This is a demo copy. Every company, contact, email, product code and note here is sample data.

## What it does
- One record per sample request: company, contact, region, products, date sent
- Status flags for new customer, new product, awaiting PO, purchased, lost bid and technical no
- Follow-up notes and next follow-up dates, with bulk follow-up across many records
- Ready-to-send follow-up emails written from each record's status
- Search, filters, sorting, duplicate merging and CSV export
- Saves edits in the browser, so it needs no server or account

## Run it
Open index.html in a browser.
